# Desktop Island (MusicOverlay)

Виджет «островок» поверх всех окон Windows: музыка, система, уведомления, звук,
буфер обмена, действия, погода, игры и лаунчер — в трёх состояниях.

## Состояния

| Состояние | Размер | Что показывает |
|---|---|---|
| **Компактное** (мини-пилюля) | 350×60 | обложка, название (печать по буквам), точки-эквалайзер |
| **Расширенное** (по нажатию ⌄) | 480×~520 | вкладки модулей + запущенные приложения |
| **Настройки** (⚙) | 480×auto | модули, внешний вид, уведомления, автозапуск |

Окно **всегда закреплено по центру экрана сверху**, поверх всех окон (WS_EX_TOPMOST),
без перехвата фокуса (WS_EX_NOACTIVATE), без кнопки в панели задач.

## Горячая клавиша

**Ctrl+Alt+M** — свернуть / развернуть (регистрируется глобально).

## Модули (вкладки расширенного вида)

1. **Музыка** — Windows Media Session: обложка, исполнитель, прогресс (перемотка кликом),
   ⏪/⏸/⏭, громкость, список активных источников, история последних треков.
   Поддержка: Spotify, YouTube (браузеры), AIMP, VLC и всё, что умеет SMTC.
2. **Система** — CPU (GetSystemTimes), GPU и диск (PDH-счётчики), RAM, сеть,
   батарея, аптайм + график CPU за 60 секунд.
3. **Уведомления** — режим «Не беспокоить», история тостов Windows (Discord, Telegram,
   Outlook, Steam…), счётчик непрочитанных, удаление записей.
   Реализовано через `UserNotificationListener` (доступ получен).
4. **Звук** — устройство вывода, общая громкость/мьют (Core Audio),
   **микшер по приложениям** (громкость и мьют каждой сессии).
5. **Буфер** — история копирований (сохраняется на диск), поиск, закрепление,
   копирование по клику, очистка.
6. **Действия** — блокировка, диспетчер задач, настройки, проводник, скриншот
   (PNG + буфер обмена), звук, DND, Bluetooth (WinRT Radio), Wi-Fi (netsh),
   схемы питания (powercfg).
7. **Погода** — часы/дата, погода с wttr.in (без ключей), прогноз на 3 дня,
   таймер с уведомлением, секундомер.
8. **Игры** — определение запущенной игры (полноэкранные окна/известные процессы),
   таймер сессии, автоматический DND при входе в игру, мини-статистика.
9. **Лаунчер** — все ярлыки «Пуск» с иконками, поиск, избранное (ПКМ → «В избранное»).

Компактный вид дополнительно показывает индикаторы эквалайзера (5 точек),
расширенный — маленький индикатор ▮▮▮▮; всё анимируется реальным системным звуком
(WASAPI loopback + FFT).

## Настройки

- **Общие** — автозапуск, горячая клавиша и опциональное перетаскивание.
- **Модули** — включение/выключение вкладок, приложений, анимации, эквалайзера.
- **Уведомления** — DND и автоматический DND при игре.
- **Внешний вид** — акцентный цвет (7 пресетов), цвет текста и фона, прозрачность, радиус скругления,
  размытие фона (DWM blur-behind).
- **О программе**.

Конфигурация: `%LOCALAPPDATA%\MusicOverlay\config.json`
(история: `notifications.json`, `tracks.json`, `clipboard.json`).

## Архитектура

```
MusicOverlay/
├── Core/
│   └── SettingsStore.cs        — единое хранилище JSON + миграция
├── Modules/                    — независимые модули
│   ├── SystemMonitorService.cs
│   ├── AudioService.cs         — Core Audio COM (микшер)
│   ├── NotificationService.cs  (в Services/)
│   ├── ClipboardService.cs
│   ├── QuickActionsService.cs
│   ├── WeatherService.cs
│   ├── GamingService.cs
│   └── LauncherService.cs
├── Services/
│   ├── MediaSessionService.cs  — SMTC + история треков
│   ├── NotificationService.cs  — UserNotificationListener + история
│   ├── ProcessMonitorService.cs— топ процессов по CPU/RAM
│   └── AudioVisualizer.cs      — loopback → FFT → 40 полос
└── MainWindow.xaml(.cs)        — три состояния, вкладки, панели
```

Каждый модуль: собственные настройки включения, состояние и события.
Выключенный модуль не работает в фоне (фильтрация вкладок + условный запуск).

## Сборка и запуск

```powershell
dotnet build C:\Users\Potho\MusicOverlay -c Release
C:\Users\Potho\MusicOverlay\bin\Release\net10.0-windows10.0.19041.0\MusicOverlay.exe
```

## Известные ограничения

- **FPS, температуры CPU/GPU, VRAM** — требуют сторонних библиотек/драйверов;
  в текущей версии не отображаются (CPU/GPU-нагрузка — да).
- **Прогресс загрузок** (Download Island) — браузеры не отдают прогресс системе.
- Переключение аудиоустройств и «яркость экрана» не реализованы
  (нужны неофициальные/привилегированные API).
- Размытие фона — через DWM blur-behind (Acrylic недоступен для прозрачных WPF-окон
  на Windows 10).
